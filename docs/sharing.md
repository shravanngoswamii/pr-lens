# Sharing

Use **Save > HTML with comments** and send the file.
Recipients download and open it in a browser.
Zip it if HTML attachments are blocked.
The file embeds the review JSON, comments and viewer assets.
Attachment previews may not run it.

For several reviewers, send one snapshot and collect their **Export feedback** files.
Import them to combine comments and copy an agent prompt.
Browser copies do not sync.

For link sharing, host revision snapshots behind sign-in and protect every reachable hostname.
A private source repository does not make hosted HTML private.
Live comments need a shared store keyed by review ID and revision, with comment IDs, authors and edit history.
Keep older snapshots so comments retain their context.
Hosting and shared storage are not included.
