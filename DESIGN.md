# Diagram workspace

User-selected layout: diagrams first, compact explanations alongside.
Taste direction: Framed sheet, seed 1589021861.

A cool neutral frame holds navigation and a white workspace.
Use no container borders or resting shadows.
IBM Plex Sans carries UI and prose. System monospace carries code.
The bundled font is unmodified Google Fonts revision `0b58fb370093f9a9f4ff785d94405710b79de67c`.

Left: review views. Center: one large diagram. Right: selected node and evidence.
Open the first diagram by default. Hash links select views and diagrams.
Keep signatures, relationships and section notes expandable.
Comments replace node details, keeping the canvas visible on desktop.
On phones, navigation folds away and details follow the diagram.

Use teal on selected nodes and focus, neutral chrome and explicit +/- diff marks.
Feedback stays separate from generated review content.
